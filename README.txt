مشروع سِراج — جاهز للبناء كـ APK
================================

المشروع يحتوي على تطبيق Android يعرض واجهة سراج الموجودة في:
app/src/main/assets/index.html

البناء من الهاتف عبر GitHub (بدون تثبيت Android Studio):
1) افتح مستودع GitHub الخاص بك.
2) ارفع محتويات هذا المجلد مباشرة إلى جذر المستودع (لا ترفع مجلد siraj-apk كطبقة إضافية).
   يجب أن يظهر build.gradle و settings.gradle ومجلد app ومجلد .github في الصفحة الرئيسية للمستودع.
3) افتح Actions ثم سير العمل Build APK.
4) اضغط Run workflow إذا لم يبدأ البناء تلقائياً بعد رفع الملفات.
5) بعد نجاح التشغيل افتح صفحة التشغيل، وانزل إلى Artifacts، ثم نزّل app-apk.
6) فك ضغط الملف الذي نزلته، وثبّت ملف APK على هاتف Android. قد يطلب الهاتف السماح بالتثبيت من هذا المصدر.

ملاحظات:
- هذا APK تجريبي (debug) وموقّع للتثبيت والاختبار، وليس إصدار متجر Play.
- ملف التطبيق الأساسي هو app/src/main/assets/index.html.
- اسم التطبيق وإصدار الحزمة في app.properties.
- ارفع محتويات المجلد كما هي، بما فيها مجلد .github المخفي.
